# ex-15 branch

**Covers:** the ex-15 branch, its feature programme, and its topology relative to master.

## Initial facts

- Purpose: next major version (15.x), planned since 2018; user's last major manual work was 2022; contributor work has continued since [RECOLLECTION:2026-09-05].
- Topology: master→ex-15 merges happen periodically; ex-15 contains a large unique commit history (whole branch history), while master contains few unique commits since the last merge — derive current state with git at task time; do not cache [CODE].
- Version: the 15.x line, with a new Extended savegame series → [savegame-versioning](savegame-versioning.md) [CODE].
- New code vs. master: `dataobj/consist_order_t.{cc,h}`, `gui/consist_order_gui.{cc,h}` (consist ordering) [CODE].
- Missing vs. master: the SDL3 backend (`sys/simsys_s3.cc`, `sys/clipboard_s3.cc`, `sound/sdl3_sound.cc`) [CODE].
- Touch hotspots (ex-15-only history): the convoy system, the schedule system and its GUI, the consist-order GUI, vehicle-list/detail GUI, vehicle descriptors, convoy assembler, settings [CODE].
- Contributor working branches: many `ex15-*` remotes (Ranran, Ceeac, Neroden, Grivlad, TransShipmentEnvoy) [CODE]. Ranran is principally a UI specialist.
